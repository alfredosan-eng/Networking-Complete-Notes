- Networking Fundamentals
- OSI & TCP/IP Models
- Encapsulation & Decapsulation
- IPv4 & IPv6
- IP Addressing
- Subnetting & CIDR
- MAC Addresses & ARP
- TCP vs UDP
- Ports & Common Protocols
- DNS
- HTTP & HTTPS
- Routing, NAT & Gateway
- Firewalls & Network Security
- Load Balancers & Proxies
- Docker Networking
- Kubernetes Networking
- Cloud Networking & AWS VPC
- Networking Cheat Sheet

## 🎯 Purpose

This project is intended to be a **clear, visual, and practical networking
reference** that can be used while studying, reviewing concepts, preparing
for technical interviews, or working with network technologies.
